# Start TRPG Chatbot

Run these steps:

1. Install dependencies if `node_modules` doesn't exist:
   ```bash
   npm install
   ```

2. Start the dev server (frontend + backend):
   ```bash
   npm run dev
   ```

3. Wait for both servers to start (look for `VITE ready` and `跑团故事引擎已启动`), then open the app:
   - Use the `run` skill or open `http://localhost:5173` in the browser
